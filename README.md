# 🌤️ Weather Estimator App

A simple and responsive Weather Web Application built using **HTML, CSS, and JavaScript**.  
It fetches real-time weather data using the **OpenWeatherMap API** and displays temperature, humidity, wind speed, and weather conditions.

---

## 🚀 Live Features

- 🔍 Search weather by city name
- 📍 Get weather using current location (Geolocation API)
- 🌡️ Real-time temperature (°C)
- 💧 Humidity and wind speed
- 🌤️ Dynamic weather icons
- 🎨 Dynamic background changes based on weather
- 📅 Live date and time display
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- OpenWeatherMap API
